# Прокат велосипедов — пользовательские кейсы

## Как читать этот документ

Что человек должен получить. Как это сделано внутри — не тема документа.

## Клиент

<!-- macstack:ref=cases[id=K-01] -->
### K-01 · Взять велосипед без очереди

- **Кто:** клиент
- **Насколько важно:** критично

Человек выбирает свободный велосипед на экране и забирает его сам.

**Готово, если:**
- свободные велосипеды видны без входа в аккаунт
- выдача занимает не больше минуты

<!-- macstack:ref=cases[id=K-02] -->
### K-02 · Вернуть велосипед на любую стойку

- **Кто:** клиент
- **Насколько важно:** важно

Возврат не привязан к той стойке, где велосипед был взят.

**Готово, если:**
- после возврата аренда закрыта и деньги списаны один раз

## Сотрудник

<!-- macstack:ref=cases[id=S-01] -->
### S-01 · Увидеть, какой велосипед не вернулся

- **Кто:** сотрудник
- **Насколько важно:** критично

Просроченная аренда видна сразу, без отчёта и без выгрузки.

**Готово, если:**
- просроченные стоят выше остальных
