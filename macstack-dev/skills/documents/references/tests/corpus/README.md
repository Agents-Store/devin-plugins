# corpus — документы, на которых плагин проверяет сам себя

Выдуманный прокат велосипедов. Шесть документов, маленькие, но настоящей формы.

**Это не пример для заказчика и не образец для нового проекта.** Единственная его
работа — дать тестам `test_v3_writer.py` что читать. Форма важнее содержания:
корпус существует ради ТРЁХ видов привязки указателя, которые проверяет перепись.

| вид | где | что значит |
|---|---|---|
| тождество | `AUTOMATION.md`, `OVERVIEW.md`, `USER-CASES.md` | id заголовка совпадает с id указателя |
| контейнер | `UX-UI.md` | три экрана указывают на две области |
| отсутствие | `OPEN-QUESTIONS.md` | зачёркнутый пункт несёт id, но не указатель |

Убрать любой из трёх — значит перестать проверять ровно то, ради чего перепись
написана, и заметить это будет нечем: тест останется зелёным.

## Чего здесь быть не должно

**Пути к чьему-либо рабочему проекту.** До 2026-08-27 тест ходил по абсолютному
пути к чужому `macstack/` — с именем пользователя в публичном репозитории. Он
краснел от законного роста тех документов, а на любой другой машине каталога не
находил, порождал три теста вместо пятнадцати и печатал `OK`. Зелено, и не
проверено ничего.

`MACSTACK_FIXTURE=<путь>` по-прежнему позволяет прогнать тесты по настоящему
проекту — свойства читателя и писателя осмысленны на любых документах. Перепись
при этом пропускается: она описывает ЭТОТ корпус.

## Если добавляете сюда документ

Обновите `CENSUS` в тесте в том же коммите — состав `corpus/` и состав `CENSUS`
сверяются `assert`-ом при загрузке, и разойтись молча они не могут.
